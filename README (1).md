# Shift Swap Request

A simple, single-page tool for shift-based teams to prepare shift swap and leave requests in one clear, standard format, ready to send to a manager for approval.

**Live demo:** https://walaahamedshedeed.github.io/shift-swap/

> This demo uses made-up sample names only. It contains no real staff or company data.

## Features

- Pick who is requesting the swap and who they are swapping with, from a fixed list (A–Z, with the manager pinned at the top)
- Add any number of days with a date picker and a shift type (D1–D5, F, N1–N3)
- Leave requests: Casual, Sick and Annual
- Writes a polite approval request to the manager automatically, with a unique reference number in the subject
- Send it by email, copy it into an email, or save it as a PDF
- Works on phones and computers

## Privacy

- Runs entirely in the browser. Nothing is uploaded or stored on any server.
- Each person's entries are saved only on their own device, so nobody sees anyone else's requests.

## Admin and staff versions

The admin version can add or remove names, shift types and manager email addresses, then create a locked **staff version**. In the staff version, people can only choose from the approved lists.

## Tech

One self-contained HTML file (HTML, CSS and plain JavaScript), with no libraries, no build step and no external requests.
